plate survey of your own browsing · everything stays in this tab

Drop a browser history file here. Any browser, any OS. Copy it first — browsers keep the file locked while running.

cp ~/Library/Application\ Support/Google/Chrome/Default/History ~/Desktop/     # Chrome, macOS
cp ~/.config/google-chrome/Default/History ~/Desktop/                          # Chrome, Linux
cp ~/Library/Safari/History.db ~/Desktop/                                      # Safari
cp ~/Library/Application\ Support/Firefox/Profiles/*.default*/places.sqlite ~/ # Firefox, macOS
cp ~/.mozilla/firefox/*.default*/places.sqlite ~/                              # Firefox, Linux
Edge · Brave · Arc · Vivaldi use Chrome's schema — same file name, different profile path.
